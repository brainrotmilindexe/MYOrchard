# Upload to GitHub

1. Sign in at https://github.com/ and choose **+ → New repository**.
2. Name it `MYOrchard`; choose Public for a portfolio or Private while learning.
3. Create the repository.
4. Choose **Add file → Upload files**.
5. Open the extracted MYOrchard folder and drag its contents (README, folders, requirements.txt) into the upload area. Upload the contents, not the ZIP itself.
6. Commit with message `Add MYOrchard analytics project`.
7. Open README.md on GitHub to review the project landing page.
Do not upload passwords, private records or personal customer data.
