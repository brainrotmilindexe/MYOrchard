# MYOrchard — Portfolio Case Study

## Summary
A fictional end-to-end analytics project for a mango wholesale operation, covering 15 synthetic harvest seasons from 2011–12 to 2025–26.

## Business questions
- How did revenue and simplified operating contribution change by season?
- Which varieties generated the most revenue and volume?
- How concentrated was revenue across buyers?
- How much harvested produce was rejected?
- How much invoiced revenue was collected?

## Workflow
Synthetic data generation → integrity validation → Python KPI analysis → SQL business questions → Power BI dashboard → written recommendations.
